This is an interactive invitation, it features three pages:<br>
         1. An RSVP page that contains a form for reservations.<br>
         2. A grad journey page that servered as an interactive story telleing to my undergrad journey (I have since removed all my personal info).<br>
         3. A mystery page that served as a thank you page, to thank the attendees.<br>
This is one of those projects that was purely just for gigs and fun, all my invitees loved it, and I loved that they loved it and was able to furter connect with each of them.<br>
The project is entirely developed using HTML/CSS and some Javascript, simple yet effective. The website is also supported on mobile which further simplified sending it to all my invitees.<br>
