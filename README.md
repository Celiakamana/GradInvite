This is an interactive invitation, it features three pages:
         1. An RSVP page that contains a form for reservations.
         2. A grad journey page that servered as an interactive story telleing to my undergrad journey (I have since removed all my personal info).
         3. A mystery page that served as a thank you page, to thank the attendees aftermath.
This is one of those projects that was purely just for gigs and fun, all my invitees loved it, and I loved that they loved it and was able to furter connect with each of them.
The project is entirely developed using HTML/CSS and some Javascript, simple yet effective.
